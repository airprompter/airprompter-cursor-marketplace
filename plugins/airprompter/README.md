# AirPrompter

Create, run, and improve AirPrompter workflows from Cursor.

## Install

Install AirPrompter from the Cursor Marketplace. Cursor registers the
bundled MCP server and prompts for AirPrompter account authorization.

## What this plugin contains

- `.cursor-plugin/plugin.json` — plugin metadata.
- `skills/airprompter/` — routing rules for saved prompts and workflows.
- `mcp.json` — names the AirPrompter MCP server.
- `assets/logo.png` — marketplace logo.

No credential, client id, or customer identifier is packaged here.
